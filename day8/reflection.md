Day 8 Assignment: Course Reflection
My Learning Reflection

The most difficult concept in this course was system design and understanding how applications handle large numbers of users at the same time. Initially, I found concepts such as horizontal scaling, load balancing, caching, database relationships and transactions challenging. I overcame these difficulties by studying the examples, completing the daily assignments and practising SQL queries. The quizzes also helped me understand important concepts and test my knowledge.

The part of my capstone project that I would improve is the system architecture and database design. Based on the feedback I received, I would focus more on improving performance, preventing duplicate data and making sure that the application can handle more users. I would also improve the user experience by making the application easier to navigate and more responsive.

Next, I want to learn more about backend development, REST APIs, database management and cloud deployment. I am also interested in learning how to build secure and scalable applications using modern technologies. I plan to continue practising JavaScript, SQL and system design by building real-world projects.

Overall, this course has helped me understand how web applications work, how databases store information and how developers design systems that can grow as more people use them. I am looking forward to applying these skills in future projects.
